Some assays were rerun only for part of the reconstructed chain. Extend the same audit and report so a clean rerun can replace analytical result authority only for descendants covered by its valid signed scope, while the physical custody and taint conclusions already established remain authoritative.

A scope signature covers the UTF-8 bytes `CUSTODY-RERUN-SCOPE-V1\n`, then `rerun=<id>\n`, `root=<custody-node-id>\n`, zero or more lexically sorted `node=<custody-node-id>\n`, zero or more lexically sorted `boundary=<custody-node-id>\n`, and zero or more lexically sorted `supersedes=<rerun-id>\n`, with no duplicate lines. Listed nodes must be descendants of the root without traversing a boundary; boundary nodes and everything beyond them are outside the scope. A valid signed revocation removes only its named rerun. On overlap, an active rerun outranks another only through the signed transitive `supersedes` relation; timestamps and counters never break ties. Preserve tainted physical material even when a covered analytical result becomes clean, and add sorted `result_authority` entries containing `original_result_id`, `authoritative_result_id`, and `authority_rerun_id` or `null`.
